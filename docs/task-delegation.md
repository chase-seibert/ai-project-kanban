# Task delegation

No Jira project, assignee, manager CC, or external delegated work is configured
for this local project. When delegation becomes appropriate, file the issue in
the assignee team’s local Jira project, assign it to the person doing the work,
notify their manager when the assignee is an engineer, and record the local
view in `tasks/tasks.md`. Follow up on the cadence agreed with the assignee;
Jira remains the source of truth for the issue.

Use this minimum request shape: context, concrete outcome, acceptance criteria,
assignee, manager notification, requested date, dependencies, and links to the
relevant StageChase docs.
